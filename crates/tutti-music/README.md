# tutti-music

Musical vocabulary for audio code: notes, time signatures and meter maps, loop ranges, and the clock that places beats on frames, so a note, a bar and a frame are each their own type.

It builds on `tutti-units` and nothing else in tutti, and it holds no audio: use it on its own, for example in a score editor or a sequencer that never renders. Most other tutti crates are built on it.

This crate is part of [tutti](https://github.com/tutti-audio/tutti), a real-time audio engine for Rust.
