# A quantity has one width, data is generic over the graph's `F`, and every crossing is a
# named place. One `<path>  <max>  <reason>` row per file that still holds a refused form;
# the gate fails on a file over its max, on a file with no row over 0, and on a row whose file
# holds no site, so the list only shrinks. The reason is `migrating: <PR or step>` (debt, which
# ends) or `spec: <the external fact>` (a width an outside specification fixes, which stays
# counted); the list ends with `spec:` rows only. The forms and what
# counts as library code are in the gate's docs (xtask/src/gates/width.rs).
