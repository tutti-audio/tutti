# Public writes of tutti-session that are not `set` on a target (`cargo xtask check-values`).
#
# One `<rule>  <file>::<Owner>::<fn>  <reason>` row per violation that is not yet gone; the
# gate fails on a violation with no row and on a row with no violation, so the list only
# shrinks. A slice that moves a value onto a target deletes its rows with the code they name.
#
# rule  setter  a `pub fn set_*`
#       set     a `pub fn set` that is not `Session::set` or `Values::set`
#       unit    a `pub` method returning `()` that takes a unit

setter  crates/tutti-session/src/graph.rs::Graph::set_feed  wiring of an event feed, a declaration: goes with the wiring declarations (11b)
setter  crates/tutti-session/src/graph.rs::Graph::set_sample_rate  the graph's prepare rate, a configuration of the detached graph: goes with the builder's rate (11a)
setter  crates/tutti-session/src/graph.rs::Graph::set_sources  wiring, a declaration: goes with the wiring declarations (11b)
setter  crates/tutti-session/src/graph/testing.rs::AudioSide::set_transport  a hand-driven transport for the detached graph, behind feature `testing`: the detached graph's test double has no session verb for the transport
setter  crates/tutti-session/src/midi.rs::Midi::set_route_fallback  goes with the MIDI routing declarations (11b)
setter  crates/tutti-session/src/midi.rs::Midi::set_routes  goes with the MIDI routing declarations (11b)
setter  crates/tutti-session/src/modulation.rs::Mods::set_source  which source a route reads, a declaration: goes at 11e
