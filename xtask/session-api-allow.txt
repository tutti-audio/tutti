# Public types of tutti-session that hold a `MainThreadMarker` (`cargo xtask check-session-api`).
#
# One `<file>::<Type>  <reason>` row per type, or `<file>::<fn>  <reason>` per borrowing `pub fn run` or
# `*_blocking`; the gate fails on a type with a marker field
# and no row, on such a function and no row, and on a row that names neither. The proof is a parameter of a
# main-thread method; a row says why a value must carry it.
crates/tutti-session/src/editor.rs::Editor  the editor handle: its calls run on the main thread and the handle holds the proof
crates/tutti-session/src/session/phases.rs::PhaseCx  a phase-stepping host's context: `main` is the proof, or none where the thread is not the main one
