# Thread starts outside `tutti-platform` that have not yet become futures (`cargo xtask check-threads`).
#
# Background work is a std `Future` on `tutti_platform::Executor`, and a blocking OS edge goes
# through `Executor::spawn_dedicated`. This file only shrinks: the gate fails on a thread start
# with no row, on a row with no start (delete it with the code it names), and on a malformed
# row, so no row is added. The audio side (the graph's render workers and the engine's timer)
# is named in the gate, not here.
#
# One `<crate>  <target>  <key>  <owner>` row per function that starts a thread.
# crate   the package the key is in
# target  what the site becomes: `spawn` (a future on the executor's pool) or
#         `spawn_dedicated` (a future on a thread of its own, for a blocking OS edge)
# key     `<file>::<fn>` for a free function, `<file>::<Owner>::<fn>` for a method; no line
#         numbers; several starts in one function share a row
# owner   the lane that migrates it: core-foundation, core-engine, plugin or midi
