#
# Interleave, deinterleave, convert and fold go through `tutti_buffers`, and a frame count
# crosses to a slice length only through `Samples::interleaved_len`. One `<key>  <reason>`
# row per function the scan finds (its doc says which shapes and which it misses); the
# gate fails on a hit with no row and on a row with no hit, so the list only shrinks.
#
# key     `<file>::<fn>` for a free function, `<file>::<Owner>::<fn>` for a method,
#         `<file>::-` outside any function.
# reason  pending      not judged yet.
#         not-interleave: <why>   judged: the stride is not a channel interleave
#                                 (complex re/im packing, a matrix row).
#
