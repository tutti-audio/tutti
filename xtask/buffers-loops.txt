# Hand interleave loops and frame-times-width lengths in `src` (`cargo xtask check-buffers`).
#
# Interleave, deinterleave, convert and fold go through `tutti_buffers`, and a frame count
# crosses to a slice length only through `Samples::interleaved_len`. One `<key>  <reason>`
# row per function the scan finds (its doc says which shapes and which it misses); the
# gate fails on a hit with no row and on a row with no hit, so the list only shrinks.
#
# key     `<file>::<fn>` for a free function, `<file>::<Owner>::<fn>` for a method,
#         `<file>::-` outside any function.
# reason  pending      not judged yet.
#         not-interleave: <why>   judged: the stride is not a channel interleave
#                                 (complex re/im packing, a matrix row).
#         atomic: <why>           judged: an interleave of atomic cells, which no
#                                 `tutti_buffers` view borrows.
#
# A free-text `measured:` is refused.
crates/tutti-dsp/src/fft/real.rs::RealFft::forward_even  not-interleave: complex re/im packing for the half-size FFT
crates/tutti-dsp/src/fft/real.rs::RealFft::inverse_even  not-interleave: complex re/im packing for the half-size FFT
crates/tutti-dsp/src/fft/staged.rs::StagedRealFft::inverse_step  not-interleave: complex re/im packing for the half-size FFT
crates/tutti-graph/src/exec/arena.rs::Arena::leading_mut  not-interleave: slot bookkeeping, the arena's lines per slot (`stride`), not a channel interleave
crates/tutti-rt/src/pos_ring.rs::copy_strided  atomic: one channel of the position ring's interleaved atomic slots, read while the writer thread fills others
