# Violations of the one building shape (`cargo xtask check-building`).
#
# One `<crate>  <rule>  <key>` row per violation that is not yet fixed; the gate fails on
# a violation with no row and on a row with no violation, so the list only shrinks. A
# lane that touches a crate deletes that crate's rows with the code they name.
#
# rule  with-prefix   a `pub fn with_*` taking `self`
#       chain-result  a chained option (`self` in, `Self` out) that returns a `Result`
#       setter        a `pub fn set_*` taking `&self` or `&mut self` on a node, source or spec
#       node-ctor     a public constructor on a `*Node`
#       config-width  a `*Config` constructor whose first parameter is not a width
#       ctor-result   a constructor returning `Result`
#       range-macro   a `macro_rules!` writing a range type outside tutti-types
# key   `<file>::<Owner>::<fn>`, or `<file>::<macro>` for `range-macro`.
